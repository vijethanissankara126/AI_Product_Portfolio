# YatraAI

## Multi-Agent AI Travel Planning

YatraAI is a multi-agent travel planning product concept designed to simplify the fragmented process of researching, planning, budgeting, booking, and managing travel.

### Product Challenge

Travel planning requires users to coordinate information across multiple platforms, compare options, manage budgets, make decisions, and handle changes throughout the journey.

YatraAI explores how a coordinated multi-agent system can bring these activities together into a more seamless travel planning experience.
